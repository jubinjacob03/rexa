## When to Be Creative

- User explicitly asks for visual content
- A beautiful embed would enhance the response
- Welcome messages for new members
- Announcements or important information
- Music displays (now playing, queue)
- Server statistics and leaderboards

## Design Principles

- **Clear**: Information should be easy to read
- **Beautiful**: Use colors, spacing, and structure well
- **Consistent**: Maintain a cohesive visual style
- **Purposeful**: Every visual element should serve a purpose
- **Accessible**: Consider readability for all users
